# Vera

> Vera was a data-centric security company delivering information rights management (IRM) as a service — encrypt, track, audit, and revoke access to files anywhere they travel, with an SDK and REST API for embedding AES 256-bit encryption and policy enforcement into applications. Acquired by HelpSystems (now Fortra) in December 2020; the product lives on as Fortra's Digital Guardian Secure Collaboration (rebranded September 2023). There is no public developer program today: the SDK/REST API is available to Fortra customers, and API introspection surfaces (e.g. application.wadl) are deliberately disabled.

Company profile maintained by API Evangelist / APIs.io. Vera was backed by Amplify Partners, Battery Ventures, Sutter Hill Ventures, and others (~$50M raised).
